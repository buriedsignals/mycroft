# Tool introduction clips

Copied from `bureau/site/static/videos/tools/` on 2026-10-29, as used by the
[technology page](https://buriedsignals.com/technology). `spotlight.mp4` is
`spotlight-intro.mp4`; the other filenames are unchanged. Spotlight and Splash
are encoded at 960px wide (H.264, CRF 26, fast-start) for the small preview.
Posters are frames
at two seconds, extracted locally with FFmpeg.

These are short promotional introductions, not demonstrations of the current
Mycroft installation. The Mycroft and desktop clips were excluded because
they still show the retired Goose runtime. Videos load only when requested,
play muted and stop when the preview closes.
