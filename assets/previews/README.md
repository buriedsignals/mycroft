# Tool introduction clips

The clips are the ones the [technology page](https://buriedsignals.com/technology)
uses, copied from `bureau/site/static/videos/`. Navigator, Scoutpost and Splash
were copied on 2026-10-29. `spotlight.mp4` was replaced on 2026-11-25 with the
research-swarm cut of the Spotlight 2.0 teaser
(`bureau/video/spotlight2/out/spotlight2-tools.mp4`, the technology page's
`videos/lab/spotlight.mp4`); the full teaser is not used because one scene
still shows the Analyst, which was removed on 2026-11-23. Spotlight and Splash
are encoded at 960px wide (H.264, CRF 26, fast-start) for the small preview.
Posters are frames at two seconds, extracted locally with FFmpeg.

These are short promotional introductions, not demonstrations of the current
Mycroft installation. Videos load only when requested, play muted and stop when
the preview closes.
